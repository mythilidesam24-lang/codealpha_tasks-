# CodeAlpha Task 1 - Web Scraping

## Project Title

Book Data Web Scraping using Python and BeautifulSoup

## Objective

The objective of this project is to collect useful information from a public website and create a structured dataset using Python web scraping techniques.

## Technologies Used

- Python
- Google Colab
- Requests
- BeautifulSoup
- Pandas

## Data Collected

- Book Title
- Price
- Availability
- Rating

## Project Description

This project uses Python and BeautifulSoup to scrape book information from a publicly available website.

The scraped information is converted into a Pandas DataFrame and saved as a CSV dataset.

The project also demonstrates scraping information from multiple web pages.

## Files

- CodeAlpha_Task1_Web_Scraping.ipynb
- books_dataset.csv
- README.md

## Learning Outcomes

- Learned the basics of web scraping
- Learned HTML structure
- Learned BeautifulSoup
- Learned how to extract information from web pages
- Learned how to create datasets using Pandas
- Learned how to save data as CSV
- Learned how to scrape multiple web pages

## Conclusion

This project demonstrates how Python and BeautifulSoup can be used to collect publicly available information from web pages and convert it into a structured dataset.
